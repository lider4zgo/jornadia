Los archivos que empiezan con guion bajo (como este) no se publican.

Para agregar un artículo, copia este archivo con otro nombre (minúsculas y guiones, por ejemplo
`reforma-40-horas.md`), cambia el encabezado y escribe el texto en Markdown:

## Subtítulo

Texto con **negritas**, *cursivas* y [enlaces](https://korporia.com).

- Listas
- con viñetas

Para la versión en inglés, crea `reforma-40-horas.en.md` con el mismo nombre más `.en`.
Quita la línea `draft: true` para publicarlo.
