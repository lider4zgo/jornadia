# Blog de korporia.com

- Un artículo = un archivo `.md` en esta carpeta: `mi-articulo.md` (español) y, si hay versión en inglés, `mi-articulo.en.md`.
- Copia `_plantilla.md` para empezar. Las imágenes van en `apps/site/public/blog/`.
- Se publica en `korporia.com/blog/mi-articulo` (y `/en/blog/mi-articulo`) al subir el cambio a `main`.
- Cada artículo lleva botones para compartir (WhatsApp, LinkedIn, Facebook y copiar enlace), la invitación a Korporia Starter y entra al sitemap y al RSS.
